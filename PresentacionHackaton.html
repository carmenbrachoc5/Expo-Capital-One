El Problema

Fatiga Financiera (B2C)

Los consumidores sufren fatiga de decisión y operan bajo modelos de crédito pasivos y estáticos.

Reglas Estáticas (Security)

Los patrones de fraude evolucionan más rápido de lo que los sistemas tradicionales pueden detectar.

Nuestra Solución

Transformamos flujos de datos en bienestar y seguridad activos.

  • Pilar 1: Autonomía Financiera. Planificador inteligente impulsado por IA (Gemini) que proyecta liquidez y automatiza el micro-ahorro basado en el estilo de vida.
  • Pilar 2: Security Sentinel. Motor de detección de anomalías en tiempo real que evalúa velocidad de transacciones y Category Hops (saltos inusuales de categoría).

Profundidad Técnica

Data Foundation: Integración directa con Capital One Nessie API para extracción de datos crudos (cuentas, retiros, depósitos).
Algorithmic Logic: En lugar de promedios simples, usamos Block Bootstrap y 10,000 simulaciones de Monte Carlo para calcular el Riesgo Condicional (CVaR).
System Design: Arquitectura limpia (PHP/MVC) que separa el Detector de Fraude (Machine Learning proxy) del Motor Financiero, todo orquestado por un modelo Gemini Flash.

Diseño y Experiencia

User Persona: "Alex Rivera" (Millennial/Gen Z). Busca maximizar sus ahorros sin sobregirarse, pero está expuesto a fraudes de e-commerce modernos.

User Journey Map:

  1. Detección: Ingreso recurrente detectado vía Nessie API.
  2. Acción Proactiva: El motor calcula un ahorro seguro al 95% y el chatbot Gemini guía la reserva.
  3. Seguridad Invisible: En cada compra, Security Sentinel evalúa silenciosamente el Category Hop y velocidad.

Mercado y Escala

TAM: Millones de usuarios de banca digital global.
SAM: +150 Millones de clientes de Capital One.
SOM: 5% de usuarios (Early adopters / 7.5M) para validación del modelo inicial.

Modelo de Negocios

  • Viabilidad: Al automatizar el ahorro seguro, Capital One incrementa agresivamente su captación de depósitos (liquidez operativa).
  • Retorno de Inversión: Reducción dramática en pérdidas millonarias por contracargos mediante bloqueos preventivos del Security Sentinel.
  • Go-To-Market: Integración nativa como un "feature" gratuito (Asistente de Resiliencia) en la app actual de Capital One. Arquitectura Cloud-native lista para escalar.

Viabilidad Operativa y Costos

Arquitectura de Alta Eficiencia: Escalable y de bajo costo inicial.

  • Costo de Desarrollo (MVP): $0. Construido ágilmente usando la API de Nessie, evitando los costos de levantar un backend bancario desde cero.
  • Infraestructura (OCI & MongoDB): ~$20 USD/mes. Despliegue en instancias ARM de Oracle Cloud con bases de datos NoSQL Serverless. Pagando solo por uso activo.
  • Inteligencia Artificial (Gemini Flash): ~$0.075 USD por 1M tokens. Modelo ultraligero que permite analizar miles de transacciones en tiempo real por centavos al día.
  • Retorno de Inversión (ROI): Operar el MVP cuesta menos de $50 USD al mes, mitigando pérdidas por fraudes que cuestan millones anuales.
